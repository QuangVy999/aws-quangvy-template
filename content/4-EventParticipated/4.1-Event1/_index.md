# Event Report: "Meetup for Networking, Knowledge Sharing, and Learning from Leaders"

### List of Speakers

- **Mr. Kiet Tran**
- **Mr. Hoang Long**
- **Mr. Thinh**
- **Mr. Xuan An**
- **Mr. Khoa Kieu and Mr. Nghi Danh**

### Key Highlights

#### Session 1: Mr. Kiet

- Shared experiences and the process of developing AI models.
- Used AI models for customer service and job interviews in enterprises.
- Presented development costs, methods for building AI models, and system architecture.
- Explained how to select suitable AI models and train them.
- Conducted a live demonstration of an AI-powered phone interview for a Cloud Engineer position in Vietnamese.

#### Session 2: Mr. Long

- Introduced AWS RAM, a service for sharing resources from parent accounts to member accounts.
- AWS RAM helps reduce operational effort and simplifies security, control, and resource management.
- Allows monitoring of resource owners, resource recipients, and their assigned permissions.

#### Session 3: Mr. Thinh

- Discussed the time and costs associated with hiring penetration testing teams to assess infrastructure.
- Used AI-powered penetration testing to improve security assessments in enterprise environments.
- Used Security Agents to identify vulnerabilities in real-world deployment environments through three key features.
- Can be integrated into GitHub and CI/CD pipelines, with some limitations regarding MFA, biometrics, and mTLS.
- Presented a video demonstration of AI-powered penetration testing agents.

#### Session 4: Mr. An

- Explored two platforms for deploying AI Agents into production.
- Used Agent Runtime to run microVMs on Amazon EC2 Spot Instances to significantly reduce costs.
- Implemented a hierarchical memory system with synchronous short-term memory and asynchronous long-term memory.
- Enabled AI Agents to gain a deeper understanding of user context.

#### Session 5: Mr. Khoa Kieu and Mr. Nghi Danh

- Presented a solution for AI Agents to operate 24/7 to support code reviews and system monitoring.
- Demonstrated how Kiro Crew generates artifacts by automatically collecting real-world data and creating visual charts.
- Context Window Management: Used the Auto Compact mechanism when context utilization reaches 70–90%.
- Used the context breakdown feature to examine token consumption in detail.

#### Lessons Learned

- I found the use of AI in customer service and job interviews extremely interesting and innovative. Traditionally, customer service and job interviews have involved direct communication between people. However, through Mr. Kiet's session, I realized that AI could take over some of these tasks, helping managers save time.
- Using AWS RAM, as introduced by Mr. Long, to share resources from parent accounts to member accounts helps save time while providing strong resource control. Although I still found his approach somewhat unclear and had not fully grasped his idea, the session helped me gain a different perspective on the AWS RAM service.
- Using AI-powered penetration testing to assess enterprise infrastructure helps reduce the cost of hiring penetration testing teams. However, security remains a concern.
